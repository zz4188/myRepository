## 🎯 技术亮点

### 架构设计
1. **分层架构**: 清晰的表示层、业务逻辑层、数据访问层
2. **模块化设计**: 高内聚低耦合，易于维护和扩展
3. **面向对象**: 充分利用类的继承和多态特性

### 安全性
1. **密码加密**: 使用 Fernet 对称加密 + PBKDF2 密钥派生
2. **不落地密码**: 内存中不存储明文密码
3. **代理支持**: 保护 IP 地址，避免被封禁
4. **安全存储**: SQLite 数据库加密存储

### 性能优化
1. **多线程**: GUI 和后端分离，避免界面卡顿
2. **异步操作**: PyQt Signal/Slot 机制
3. **连接池**: 数据库连接优化
4. **缓存机制**: 登录状态缓存

### 反爬虫
1. **随机延迟**: 避免请求频率过高
2. **随机 User-Agent**: 模拟不同浏览器
3. **代理轮换**: 动态更换 IP
4. **请求头伪装**: 模拟真实用户访问
5. **Cookie 管理**: 保持登录状态

### 用户体验
1. **现代化 UI**: 美观的界面设计
2. **系统托盘**: 最小化到托盘，不干扰工作
3. **实时日志**: 即时查看操作状态
4. **友好提示**: 详细的错误信息和操作指导
5. **快捷操作**: 支持双击编辑、右键菜单等

## 🚀 使用指南

### 快速开始

1. **安装依赖**
```bash
pip install -r requirements.txt
```

2. **运行程序**
```bash
python main.py
```

或双击运行 `run.bat`

### 基本操作

1. 添加账号 → 测试连接 → 保存
2. 创建任务 → 设置参数 → 添加到调度器
3. 查看日志 → 监控抢票进度
4. 系统设置 → 调整参数 → 保存

### 打包为 exe

```bash
python build_exe.py
```

生成文件位于: `dist/TicketMaster/TicketMaster.exe`
