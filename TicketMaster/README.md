# TicketMaster - Windows 抢票软件

一个功能完整的 Windows 桌面应用，支持 12306、大麦网、携程三大平台的自动抢票功能。

## 功能特性

### 核心功能
- ✅ **多平台支持**：12306（火车票）、大麦网（演唱会门票）、携程（酒店/机票）
- ✅ **自动登录**：支持多账号管理，自动登录各平台
- ✅ **智能抢票**：实时监控余票，自动下单
- ✅ **定时任务**：设置定时抢票，支持一次性或周期性任务
- ✅ **日志系统**：完整的操作日志和错误记录
- ✅ **账号管理**：安全的密码加密存储，多账号并行管理

### 技术特性
- 现代化的 PyQt6 GUI 界面
- Selenium + requests 双重爬虫引擎
- SQLite 数据库存储
- APScheduler 定时任务调度
- 系统托盘支持
- 代理配置支持
- 反爬虫机制（随机延迟、请求头伪装）

## 安装说明

### 环境要求
- Python 3.10 或更高版本
- Windows 10/11 操作系统

### 从源码安装

1. 克隆仓库：
```bash
git clone <repository-url>
cd TicketMaster
```

2. 安装依赖：
```bash
pip install -r requirements.txt
```

3. 运行程序：
```bash
python main.py
```

### 使用安装包

1. 下载 `TicketMaster-1.0.0-setup.exe`
2. 双击运行安装程序
3. 按照安装向导完成安装
4. 从桌面快捷方式启动程序

## 使用指南

### 1. 账号管理

1. 启动程序后，点击"账号管理"标签页
2. 点击"添加账号"按钮
3. 选择平台（12306/大麦网/携程）
4. 输入用户名和密码（密码会自动加密存储）
5. 点击"测试连接"验证账号是否可用
6. 点击"保存"完成账号添加

### 2. 创建抢票任务

#### 12306 火车票

1. 点击"抢票任务"标签页
2. 点击"创建任务"
3. 选择平台：12306
4. 填写任务信息：
   - 任务名称
   - 出发地、目的地
   - 出发日期
   - 车次类型（可选）
   - 座席类型
5. 选择要使用的账号
6. 设置执行时间或立即执行
7. 点击"创建任务"

#### 大麦网演唱会门票

1. 点击"创建任务"
2. 选择平台：大麦网
3. 填写任务信息：
   - 活动名称或链接
   - 演出日期
   - 票档选择
   - 购买数量
4. 选择账号
5. 设置执行时间
6. 点击"创建任务"

#### 携程酒店/机票

1. 点击"创建任务"
2. 选择平台：携程
3. 填写任务信息：
   - 城市/出发地
   - 入住/出发日期
   - 离店/到达日期
   - 价格范围
4. 选择账号
5. 设置执行时间
6. 点击"创建任务"

### 3. 定时任务

1. 创建任务时设置"执行时间"
2. 支持一次性任务和周期性任务
3. 周期性任务可设置：
   - 每天执行
   - 每周执行
   - 每月执行
   - 自定义间隔
4. 任务可在"抢票任务"页面查看和管理
5. 可随时暂停、删除任务

### 4. 日志查看

1. 点击"日志"标签页
2. 查看所有操作日志和错误日志
3. 日志类型：
   - INFO：普通操作信息
   - SUCCESS：成功信息（抢票成功）
   - WARNING：警告信息
   - ERROR：错误信息
4. 支持按时间、类型筛选
5. 可导出日志到文件

### 5. 系统设置

1. 点击"设置"标签页
2. 可配置：
   - 代理设置（HTTP/SOCKS5）
   - 抢票重试次数
   - 请求延迟时间
   - 浏览器驱动路径
   - 日志保留天数
3. 点击"保存设置"应用配置

## 技术架构

### 技术栈
- **GUI 框架**：PyQt6
- **网络请求**：requests, selenium
- **数据库**：SQLite
- **定时任务**：APScheduler
- **加密**：cryptography
- **打包工具**：PyInstaller

### 核心设计

1. **分层架构**
   - GUI 层：用户界面
   - 业务逻辑层：抢票逻辑、任务调度
   - 数据层：数据库操作
   - 平台层：各平台具体实现

2. **多线程设计**
   - 主线程：GUI 界面
   - 工作线程：抢票任务、定时任务
   - 通过 PyQt Signal/Slot 机制通信

3. **安全性**
   - 密码使用 Fernet 对称加密
   - 代理支持保护 IP
   - 请求头伪装

4. **反爬虫**
   - 随机请求延迟
   - 随机 User-Agent
   - 代理轮换
   - Cookie 管理

## 常见问题

### 1. 登录失败怎么办？
- 检查账号密码是否正确
- 尝试使用代理
- 检查是否需要验证码
- 查看日志了解详细错误信息

### 2. 抢票总是失败？
- 调整请求延迟时间
- 使用代理 IP
- 检查账号状态
- 查看日志分析失败原因

### 3. 程序无法启动？
- 确认 Python 版本 >= 3.10
- 安装所有依赖：`pip install -r requirements.txt`
- 检查是否有防火墙拦截

### 4. Selenium 驱动问题？
- 下载对应版本的 ChromeDriver
- 在设置中配置驱动路径
- 或使用自动管理工具：`pip install webdriver-manager`
