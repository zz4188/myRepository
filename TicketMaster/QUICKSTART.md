# TicketMaster 快速入门指南

## 📦 快速安装

### 方式一：从源码运行

1. **安装 Python**
   - 下载 Python 3.10 或更高版本：https://www.python.org/downloads/
   - 安装时勾选 "Add Python to PATH"

2. **安装依赖**
   ```bash
   cd TicketMaster
   pip install -r requirements.txt
   ```

3. **运行程序**
   ```bash
   python main.py
   ```

或者直接双击运行 `run.bat`

### 方式二：使用安装包

1. 下载 `TicketMaster-1.0.0-setup.exe`
2. 双击运行安装程序
3. 从桌面快捷方式启动

## 🚀 使用流程

### 1️⃣ 添加账号

1. 启动程序后，点击"账号管理"标签页
2. 点击"➕ 添加账号"
3. 选择平台（12306/大麦网/携程）
4. 输入用户名和密码
5. 点击"测试连接"验证
6. 点击"保存"

**提示**：密码会自动加密存储，安全可靠

### 2️⃣ 创建抢票任务

#### 12306 火车票

1. 点击"🎫 抢票任务"标签页
2. 点击"➕ 创建任务"
3. 基本信息：
   - 任务名称：如"北京到上海"
   - 平台：选择 12306
   - 任务类型：选择"一次性"或周期性
   - 执行时间：设置开始抢票的时间

4. 账号选择：
   - 勾选要使用的账号

5. 任务参数：
   - 出发地：如"北京"
   - 目的地：如"上海"
   - 日期：选择出发日期
   - 座位类型：如"二等座"
   - 购买数量：选择张数

6. 点击确定

#### 大麦网演唱会

1. 步骤同上，平台选择"大麦网"
2. 任务参数：
   - 出发地/城市：演出城市
   - 庆位类型/票档：如"看台票"
   - 购买数量：选择张数

#### 携程酒店/机票

1. 步骤同上，平台选择"携程"
2. 任务参数：
   - 出发地/城市：目的地城市
   - 日期：入住/出发日期
   - 数量：房间数

### 3️⃣ 管理任务

- **查看任务**：任务列表显示所有任务及其状态
- **编辑任务**：双击任务或点击"✏️ 编辑"
- **暂停/恢复**：点击"⏸️ 暂停"或"▶️ 恢复"
- **立即执行**：点击"▶️ 立即执行"立即开始抢票
- **删除任务**：点击"🗑️ 删除"

### 4️⃣ 查看日志

1. 点击"📋 日志查看"标签页
2. 实时查看所有操作日志
3. 不同颜色表示不同级别：
   - 🔵 INFO：普通信息
   - ⚠️ WARNING：警告
   - 🔴 ERROR：错误
   - 🟢 SUCCESS：成功
4. 双击日志条目查看详细信息
5. 点击"📥 导出日志"保存日志文件

### 5️⃣ 系统设置

1. 点击"⚙️ 系统设置"标签页
2. 配置各项参数：
   - **代理设置**：使用代理 IP 保护
   - **请求设置**：调整请求超时、重试次数
   - **抢票设置**：配置抢票策略
   - **浏览器设置**：选择浏览器类型、无头模式
   - **日志设置**：设置日志级别和保留天数
   - **通知设置**：启用声音和弹窗提示
3. 点击"💾 保存设置"

## ⚡ 高级功能

### 定时任务

- **每天执行**：每天固定时间抢票
- **每周执行**：每周固定日期和时间
- **每月执行**：每月固定日期和时间
- **自定义间隔**：自定义重复间隔（秒）

### 系统托盘

- 程序最小化到系统托盘
- 双击托盘图标显示/隐藏窗口
- 右键托盘图标可快速退出

### 多账号并发

- 可为每个任务分配多个账号
- 提高抢票成功率

## 🛠️ 故障排除

### 登录失败

1. 检查用户名和密码是否正确
2. 尝试使用代理
3. 检查是否需要验证码（需要人工处理）

### 浏览器驱动问题

**错误信息**：'chromedriver' executable needs to be in PATH

**解决方案**：

方式一：自动管理（推荐）
```bash
pip install webdriver-manager
```

方式二：手动安装
1. 下载与 Chrome 版本匹配的 ChromeDriver
2. 下载地址：https://chromedriver.chromium.org/downloads
3. 在"系统设置"→"浏览器设置"中配置驱动路径

### 程序无法启动

1. 检查 Python 版本（需要 3.10+）
2. 重新安装依赖：`pip install -r requirements.txt`
3. 检查防火墙是否拦截

### 抢票总是失败

1. 调整请求延迟时间（设置中调大）
2. 使用代理 IP
3. 检查账号状态（是否被限制）
4. 查看日志了解详细错误

## 📋 打包为 exe

1. 确保已安装 PyInstaller
   ```bash
   pip install pyinstaller
   ```

2. 运行打包脚本
   ```bash
   python build_exe.py
   ```

3. 生成的文件位于：`dist/TicketMaster/TicketMaster.exe`

4. （可选）使用 NSIS 创建安装包
   - 安装 NSIS：https://nsis.sourceforge.io/
   - 右键点击 `installer.nsi` → "Compile NSIS Script"

   - 提前添加并测试账号

   - 准备多个账号备用

3. **任务策略**

   - 定期测试账号连接
   - 避免频繁登录被限制
   - 每个账号创建独立任务
