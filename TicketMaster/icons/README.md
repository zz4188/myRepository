# TicketMaster 图标说明

本目录用于存放应用程序图标文件。

## 所需图标

需要创建以下图标文件：

### app_icon.ico
- 应用程序主图标（用于任务栏、窗口标题栏等）
- 尺寸：建议 256x256, 128x128, 64x64, 48x48, 32x32, 16x16 多尺寸组合
- 格式：ICO 格式
- 颜色：建议使用蓝色为主色调，配合抢票相关的元素（如票、时钟、闪电等）

### 其他可选图标
- logo.png：用于文档和演示
- splash.png：启动画面（可选）

## 图标制作建议

可以使用以下工具制作图标：

1. **在线工具**
   - https://www.icoconverter.com/
   - https://icoconvert.com/

2. **专业软件**
   - Adobe Photoshop（需安装 ICO 插件）
   - GIMP（免费）
   - IcoFX（专业图标编辑器）

3. **简单方法**
   - 创建一张 PNG 图片（建议 256x256 或更大）
   - 使用在线转换工具转换为 ICO 格式

## 临时解决方案

如果暂时没有合适的图标，可以使用以下方法：

1. 从网上搜索免费可商用的火车票、演唱会票等图标
2. 使用 Windows 系统自带图标
3. 使用 PyInstaller 打包时不指定图标（spec 文件中 icon 参数设为 None）

## 注意事项

- 确保图标版权清晰，使用免费可商用的图标资源
- 图标应该简洁明了，易于识别
- 多尺寸组合确保在不同分辨率下都清晰可见
